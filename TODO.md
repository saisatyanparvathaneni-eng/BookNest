# BookNest delivery outcomes

## Responsive BookNest storefront
- [x] Responsive BookNest storefront with a warm editorial bookstore visual style and accessible navigation.

## Curated catalogue and discovery
- [x] Curated book catalogue with illustrated book cards, titles, authors, categories, ratings, prices, badges, and detail views.
- [x] Search books by title, author, category, or description.
- [x] Filter the catalogue by category and sort by featured order, price, or rating, with clear-filter behavior.
- [x] Category browsing and promotional offer links that take readers to matching catalogue views.

## Local shopping and demo flows
- [x] Local shopping bag with add, remove, quantity controls, subtotal, tax, shipping, free-shipping threshold, and total calculations.
- [x] Demo account flow supporting sign-in and account creation stored only in the current browser without storing passwords.
- [x] Demo checkout flow collecting delivery details, offering simulated payment methods, and showing a local order confirmation without processing payment.
- [x] Newsletter signup interaction that confirms locally without sending email.

## Accessibility and persistence
- [x] Responsive accessibility-minded behavior including skip navigation, keyboard-visible focus states, reduced-motion support, mobile navigation, and light/dark theme persistence.
