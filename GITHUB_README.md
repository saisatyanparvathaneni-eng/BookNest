# BookNest — GitHub-ready static webpage

BookNest is a responsive, dependency-free bookstore storefront demo built with semantic HTML, CSS, and vanilla JavaScript.

## Test it in another browser

### Option 1: Open directly
Open `index.html` in a modern browser such as Chrome, Edge, Firefox, or Safari.

### Option 2: Run a local server
From this folder, run:

```bash
python3 -m http.server 3000
```

Then visit `http://localhost:3000` in your browser.

No package installation, API key, database, payment gateway, or backend is required.

## Files

- `index.html` — complete webpage structure, catalogue sections, forms, and dialogs.
- `styles.css` — responsive layout, design tokens, light/dark theme, and mobile breakpoints.
- `script.js` — book data, search, filtering, sorting, cart, demo account, checkout, and newsletter behavior.
- `screenshots/booknest-desktop-full.png` — full-page desktop reference screenshot.
- `screenshots/booknest-mobile-full.png` — full-page mobile reference screenshot.
- `README.md` — full project report and feature notes.
- `manus-routes.json`, `app.config.ts`, `package.json`, `TODO.md` — supporting project metadata.

All account, checkout, newsletter, payment, and delivery behavior is simulated locally in the browser. Do not enter real credentials or payment details.
